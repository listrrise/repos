# dinapenis + dinagestures

**Sileo-репозиторий:** `https://listrrise.github.io/repos/`

## dinapenis (v0.3.0) — Dynamic Island для iOS 12–15
- Остров-пилюля поверх всего, музыка, звонки, свайпы треков.
- Локскрин: раскрытие в ширину с рисованной иконкой замка и временем;
  разблокировка — morph в открытый замок и схлопывание.
- Зарядка: широкий бар с рисованной иконкой батареи и процентами.
- Фейк-активность в настройках для превью острова.
- Настройки: «Настройки → dinapenis».

## dinagestures (v0.1.0, отдельный твик) — жесты iPhone X, категория Any iOS
- Полоска-индикатор снизу (134×5): авто-цвет по теме (тёмная — белая,
  светлая — чёрная) или вручную белая/чёрная. Только картинка, тапы не ест.
- Свайп вверх от нижнего края = домой (в каждом приложении).
- Подъём контента (+20pt к safe area снизу, настраивается 0–34),
  чтобы полоска не наезжала на кнопки. Алерты не трогаем.
- Грузится в SpringBoard (полоска) и все UIKit-приложения (жест + отступ).

## Состав (v0.3.0)
- **Остров**: пилюля 126×37 поверх всего (включая локскрин),
  спринг-анимация, компактный режим (иконка + waveform/пульс).
- **Музыка и звонки**: Now Playing (название, артист, обложка),
  звонки через CallKit.
- **Свайпы**: влево — предыдущий трек, вправо — следующий
  (MediaRemote через dlopen). Тап — раскрыть/схлопнуть.
- **Локскрин**: при блокировке остров раскрывается в ширину
  с рисованной иконкой замка и временем; при разблокировке —
  morph в открытый замок и схлопывание.
- **Настройки**: «Настройки → dinapenis», применяются на лету,
  кнопка Respring (работает на rootful и rootless).

## Сборка локально (Theos)
```bash
export THEOS=~/theos
make package            # rootful
make package THEOS_PACKAGE_SCHEME=rootless   # rootless
```

## Ограничения
- Таймеры/AirPods в острове — нет (приватные фреймворки по версиям).
- На безчёлочных SE/8 пилюля висит по центру.
