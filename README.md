# dinapenis — Dynamic Island для iOS 12–15

**Sileo-репозиторий:** `https://listrrise.github.io/repos/`

## Состав (v0.2.0)
- **Остров**: пилюля 126×37 поверх всего (включая локскрин),
  спринг-анимация, компактный режим (иконка + waveform/пульс).
- **Музыка и звонки**: Now Playing (название, артист, обложка),
  звонки через CallKit.
- **Свайпы**: влево — предыдущий трек, вправо — следующий
  (MediaRemote через dlopen). Тап — раскрыть/схлопнуть.
- **Локскрин**: при блокировке остров раскрывается с замком 🔒
  и текущим временем; при разблокировке замок morph'ится в 🔓
  и остров схлопывается.
- **Настройки**: «Настройки → dinapenis», применяются на лету,
  кнопка Respring (работает на rootful и rootless).

## Сборка локально (Theos)
```bash
export THEOS=~/theos
make package            # rootful
make package THEOS_PACKAGE_SCHEME=rootless   # rootless
```

## Ограничения
- Таймеры/AirPods/зарядка в острове — нет (приватные фреймворки по версиям).
- На безчёлочных SE/8 пилюля висит по центру.
